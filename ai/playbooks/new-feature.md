# Playbook: new feature

1. **Issue** — open (or pick) a GitHub issue using the Feature template. Say what and why.
2. **Check decisions** — read `docs/decision/README.md`. Does the feature touch a Decided
   topic? Does it need a new decision? If yes, record/supersede it first (`record-decision`).
3. **Branch** — `feat/<short-name>` from latest `main`.
4. **Build** — small commits. Add tests once a stack and test approach are Decided.
5. **Update the hub** — new domain terms → glossary; new gotchas → `ai/knowledge/`.
6. **PR** — fill in the PR template; link the issue and any decision docs; request review.
7. **Merge** — squash-merge after approval; delete the branch.
